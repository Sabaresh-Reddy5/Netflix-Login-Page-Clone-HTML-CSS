# Netflix-Login-Page-Clone-HTML-CSS
A modern, responsive Netflix Login Page Clone built using HTML and CSS. The page includes animated input fields, a clean UI, a dark-themed design, and mobile responsiveness. Perfect for beginners practicing frontend development and UI design.

🎬 Netflix Login Page Clone – HTML & CSS

This project is a fully responsive Netflix Login Page Clone created using pure HTML and CSS. The goal of this mini-project is to replicate the clean and modern UI of Netflix’s sign-in interface while practicing real-world frontend skills.

The design includes a realistic dark theme, branded styling, smooth input animations, and a mobile-friendly layout. No JavaScript is used, making the project simple yet visually appealing and ideal for beginners building their frontend portfolio.

🔧 Technologies Used

HTML5 – Structure and layout

CSS3 – Styling, responsiveness, and animations

Google Fonts – Clean text styling

Flexbox & Positioning – Layout management

Media Queries – Responsive design

⭐ Features

Netflix-style UI with logo and background overlay

Animated floating labels for input fields

Responsive design for mobiles & tablets

Styled “Sign In” button and Remember Me toggle

Clean, modern aesthetic matching the Netflix theme

No JavaScript needed

📂 Project Structure
/index.html       -> Main login page
/style.css        -> Styling and layout design

This project was created to practice:
